App updates

Update the dashboard software. To collect new findings, use Sync feeds.

  1. Back up the archive on your NAS.
  2. Select Update app. The request waits for DSM Task Scheduler. To start now, select the updater task in DSM and click Run.
  3. When you see Update complete, select Reload dashboard.
